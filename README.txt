# TRIZED TCG — Free Static Website

This is a starter website for TRIZED TCG.

## Quickest free setup: GitHub Pages

1. Create a free GitHub account.
2. Create a new public repository, e.g. `trized-tcg`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. In the repository, open Settings → Pages.
5. Choose "Deploy from a branch", select `main`, and save.
6. GitHub will give you a free `github.io` website address.

## Customize

- Replace the example products in `script.js` with your real inventory.
- Replace the `#` Shopee links with your actual Shopee store/product links.
- Change prices, set names, and card numbers in `script.js`.
- A custom domain can be connected later if you decide to buy one.

No server or paid hosting is required for this version.
